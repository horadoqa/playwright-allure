Automação de testes

Playwright

Para começar a trabalhar com Playwright, configure seu ambiente de desenvolvimento com as ferramentas abaixo.

Requisitos

No Windows, instale os seguintes recursos antes de começar.

Node.js

Necessário para executar o Playwright e seus projetos.

→

Git Bash

Utilize o Git Bash como linha de comando para executar os comandos do projeto.

→

Visual Studio Code

Editor recomendado para desenvolver, executar e depurar os testes.

→

Extensão do Playwright

Extensão para o VS Code que facilita a criação, execução e depuração dos testes.

→

Ambiente pronto?

Depois de instalar os requisitos, você estará pronto para configurar o Playwright e começar a criar seus primeiros testes automatizados.
